Este archivo habla sobre la configuración del servidor HTTP (apache)

ÍNDICE:

1)instalación
2)configuracion
3)licenciamiento y soporte

1) INSTALACIÓN:

-> para instalar apache se debe utilizar: "SUDO DNF INSTALL HTTPD -Y"
-> esto instala apache desde los repositorios oficiales de almalinux

2) CONFIGURACIÓN

-> sudo systemctl start httpd => levanta el servidor

-> sudo systemctl enable => para que al momento de reniniciar no se caiga

-> sudo systemctl restart => reinicia el servidor http

-> sudo systemctl status => indica el estado actual del servidor


 CONFIGURACÓN: ubicaciones:

-> una vez instalado apache, por defecto, el directorio raíz del servidor web suele ser /var/www/html
   aquí puedes colocar tus arhivos (index.html,index.php,etc), es importante pues aquí irán los proyectos
   del equipo y/o la plataforma web de desarrollo en cuestión.

-> para acceder a estas carpetas/archivos desde el servidor debes ingresar desde un navegador la dirección
   IP http://127.0.0.1 o http://localhost/miArchivo.php

-> los arhivos de configuracion principal de apache se encuentran en /etc/httpd/conf/httpd.conf


3) LICENCIAMIENTO Y SOPORTE:

-> Apache está bajo la licencia "Apache License 2.0" que es gratuita y de código abierto, se puede
   usar de forma totalmente gratuita en casi cualquier tipo de proyecto. La comunidad es quien le da
   mantenimiento (fotos y documentacion oficial: http://httpd.apache.org/docs).

->También cuenta con soporte comercial, como Red Hat que incluye un mantenimiento de apache en algunos
  de sus planes de suscripción y proveedores de hosting que ofrcen soporte
