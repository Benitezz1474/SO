1) COMO INSTALAR MYSQL:

Para instalar MYSQL se deben realizar los siguientes pasos:

-> #SUDO DNF INSTALL MARIADB-SERVER -Y# 

-> se debe tener en cuenta que esto instala los servicios que estan "por defecto"
   en los repositorios de almalinux

2) CONFIGURACIÓN:

   -> para ver la configuración del servicio de base de datos de mariaDB, debe ir
      al archivo ubicado en /etc/my.cnf, este contiene los parametros basicos que vienen
      por defecto al utilizar los servicios de maraiaDB, se pueden reajustar/cambiar.

   -> systemctl status mariadb => permite visualizar el estado del cliente de mariaDB

   -> systemctl start mariadb => inicia el servicio de base de datos de mariadb

   -> systemctl restart mariadb => reinicia el servicio de bases de datos de mariadb

   -> systemctl enable mariadb => eso evita que se apague el servicio de base de datos al reiniciar 

  CONFIGURACION DE RESPALDOS Y RECUPERACIÓN:
   
    -> para realizar respaldos y recuperaciones de una BBDD, utilzando el servicio de base de datos mariaDB se debe
       utilizar el comando mysqldump, a continuación ejemplos basicos de uso:
      
    -> para respaldar: mysqldump -u "nombreUusario" -p"clave"  "nombreBBDD" > archivo.sql
   
    -> para recuperar: mysqldump -u "nombreUsuario" -p"clave" "nombreBBDD" < arhivo
